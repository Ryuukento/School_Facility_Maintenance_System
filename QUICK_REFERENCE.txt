🆘 QUICK TROUBLESHOOTING:
════════════════════════════════════════════════════════════════════════════

Issue: Still seeing XAMPP page
  → Stop Apache → Wait 2 sec → Start Apache
  → Clear browser cache (Ctrl+Shift+Delete)
  → Hard refresh (Ctrl+Shift+R)

Issue: Login fails
  → Verify database exists in phpMyAdmin
  → Check admin user in users table
  → Verify MySQL is running

Issue: Sidebar not showing
  → Check sidebar files exist:
     - frontend/includes/sidebar.php
     - frontend/assets/css/sidebar.css
     - frontend/assets/js/sidebar.js
  → Clear browser cache and refresh

Issue: Port already in use
  → XAMPP Control Panel → Apache Config
  → Change port from 80 to 8080
  → Visit: http://localhost:8080/School_Facility_Maintenance_System/

For detailed help → XAMPP_TROUBLESHOOTING.md
