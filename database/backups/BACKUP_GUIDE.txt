School Facility Maintenance System - Clean SQL Backup Guide

Why this exists:
- phpMyAdmin exports can include internal pma__ tables from phpmyadmin database.
- Those tables can cause import errors like: #1050 Table 'pma__bookmark' already exists.

Use this script:
- database/backups/make-clean-backup.ps1

Quick command (run from project root):
- powershell -ExecutionPolicy Bypass -File database/backups/make-clean-backup.ps1

Custom input file:
- powershell -ExecutionPolicy Bypass -File database/backups/make-clean-backup.ps1 -InputFile school_facility_maintenance.sql

Custom output folder:
- powershell -ExecutionPolicy Bypass -File database/backups/make-clean-backup.ps1 -OutputDirectory .

Output format:
- school_facility_maintenance-clean-YYYYMMDD_HHMMSS.sql

Recommended import flow:
1) Open phpMyAdmin.
2) Select database school_facility_maintenance (or create it first).
3) Import the generated clean SQL file.

Tip:
- Keep the original dump file untouched.
- Always import the generated *-clean-*.sql file.
