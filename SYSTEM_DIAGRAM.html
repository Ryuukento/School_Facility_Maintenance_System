👥 User Roles & Permissions
👨‍🎓
Student / Staff
  • • Submit maintenance reports
  • • Track report status
  • • View own reports
  • • Receive notifications
🔧
Maintenance Admin
  • • View assigned reports
  • • Update report status
  • • Assign technicians
  • • Generate reports
  • • Manage facilities
👨‍💼
Super Admin
  • • Full system access
  • • Manage all users
  • • View all reports
  • • System settings
  • • Dashboard analytics
🔄 Report Submission Data Flow
1
User submits report via form (Student/Staff)
2
Frontend validates input and sends POST to API
3
API Layer receives request, checks authentication
4
Controller passes data to ReportService
5
ReportService validates and processes the report
6
AssignmentService auto-assigns to maintenance admin
7
Model inserts report into database
8
NotificationService creates notifications for admin
9
EmailService sends email alerts (optional)
10
Response returned to frontend with success/error
