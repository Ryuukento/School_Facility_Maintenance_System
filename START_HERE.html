🏫 School Facility Maintenance System

Installation & Quick Start Guide

✓ System Ready!

Your SFMS is ready to install. Follow the steps below to get started.

1 Start Your Server

For Laragon:

Open Laragon → Click "Start All"

For XAMPP:

Open XAMPP Control Panel → Start Apache & MySQL

2 Copy This Folder

For Laragon:

Copy to: C:\laragon\www\School_Facility_Maintenance_System\

For XAMPP:

Copy to: C:\xampp\htdocs\School_Facility_Maintenance_System\

3 Import Database

  1. Open: http://localhost/phpmyadmin
  2. Click "Import" tab
  3. Choose file: database/setup.sql
  4. Click "Go"
  5. Wait for "Success" message

4 Access Your System

Open your browser and go to:

http://localhost/School_Facility_Maintenance_System/
